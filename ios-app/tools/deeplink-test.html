深链唤醒测试

点下面的链接，看能不能跳到「在线客服」APP。全部用同一个 URL Scheme：ifengadmin

前提：APP 至少要手动打开过一次，系统才会注册它声明的 Scheme。 刚装完还没点开过，下面所有链接都会没反应——这不是 bug。
正常链接（应该能唤醒）
打开会话 #1/conversation/1 打开会话 #123/conversation/123 带账户校验?account_id=2 只唤醒，不带参数ifengadmin://
自定义会话 ID
非法链接（应该被忽略，不跳转）
ID 不是数字/conversation/abc 多余参数?foo=bar 路径不对/other/1

怎么判断成功了

  • 跳到了 APP → Scheme 注册成功，深链通路没问题。
  • 跳到 APP 但停在登录页 → 也成功了。未登录时 APP 会先让你登录，登录完成后再自动跳到目标会话。
  • 跳到 APP，提示「会话不存在或没有访问权限」 → 也成功了，只是这个 ID 在服务端不存在或不属于你。
  • 跳到 APP，顶部提示「该会话不属于当前账户」 → 也成功了，说明 account_id 校验生效。
  • 点了没反应 / 弹「Safari 打不开网页」 → 见下面的排查。

点了没反应，按顺序排查

  1. 先手动点开一次 APP 图标，然后回到这个页面再点链接。
  2. 确认装的是这次编译出来的包，不是旧版本。APP 里能正常登录就说明是新的。
  3. 如果你用自签工具重签过，检查有没有改过 Bundle ID。Scheme ifengadmin 写在 Info.plist 里，重签一般会保留，但如果工具「优化」过 plist 可能被删。
  4. 手机上是不是同时装了两个声明 ifengadmin 的包？系统只会给其中一个，删掉多余的那个。
  5. 在 Safari 地址栏直接敲 ifengadmin://conversation/1 回车，如果弹出「在"在线客服"中打开？」，点「打开」——能弹这个框就说明 Scheme 是好的，只是页面内链接被拦了。
  6. 以上都不行，用「快捷指令」App 建一个「打开 URL」的快捷指令，填 ifengadmin://conversation/1 运行。这是最不受浏览器策略影响的方式。

注意：Safari 地址栏 ≠ 页面链接

iOS Safari 地址栏直接输入自定义 Scheme，经常会被当成搜索词处理，行为不稳定。 页面里点链接才是可靠的测试方式。另外，从别的 App（微信、备忘录）里点开这个链接通常也会被拦， 最稳的是 Safari 里的真实 <a href> 链接，或者「快捷指令」。
